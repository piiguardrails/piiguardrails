Install the Community Node in n8n

You can install the official community package directly from inside your n8n workspace:

  1. In your n8n interface, open Settings (gear icon) > Community Nodes.
  2. Click Install a community node.
  3. Enter the package name: n8n-nodes-piiguardrails
  4. Check the confirmation box and click Install.
Self-Hosted / Docker CLI alternative: If running n8n via Docker or npm, you can install directly into your n8n root directory:
npm install n8n-nodes-piiguardrails

Frequently Asked Questions

Q: I get "ECONNREFUSED" when testing credentials with localhost:8000

If your n8n instance is running inside a Docker or Podman container, localhost refers to the n8n container itself. Change the Base URL to http://host.containers.internal:8000 (Podman) or http://host.docker.internal:8000 (Docker) so n8n can reach the host machine.

Q: Does Enterprise PII Guardrails store or retain our prompts?

Zero Retention Guaranteed. The engine processes tokens strictly in ephemeral memory. No prompts, customer data, or token mappings are ever saved to disk or transmitted outside your local environment.

Q: How do I handle quota limits on the free sandbox?

The hosted sandbox at https://demo.piiguardrails.com provides 50 free requests per browser session for evaluation. For production workloads or unlimited requests, launch your own on-premise container using Docker or contact us.
